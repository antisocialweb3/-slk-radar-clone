# SLK Radar-inspired Scanner

A responsive, mobile-friendly dashboard prototype inspired by the public-facing features of SLK Radar. This is an independent implementation, not the original website or source code.

## Current status

- Responsive dark dashboard UI
- Demo watchlist with Forex, Metals, Crypto, and Indices filters
- Symbol search
- Clearly labelled demo data; no live market feed or validated signal engine yet

## Preview

Open `index.html` in a browser. You can also launch GitHub Codespaces to continue development from your phone.

## Planned next steps

1. Connect a suitable market-data provider.
2. Define and test the higher-timeframe level/sweep and lower-timeframe confirmation rules.
3. Add historical testing and duplicate-alert prevention.
4. Add optional Telegram notifications.

**Important:** The values currently shown are fictional examples for interface testing, not live prices or trading signals.
